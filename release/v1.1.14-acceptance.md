# Fact-Check-X v1.1.14 acceptance record

Fact-Check-X v1.1.14 fixes one Doubao source-count boundary reported from a real WorkBuddy run. It does not add a platform, external model API or workflow stage.

## Accepted behavior

1. The collector records Doubao's platform-declared source count separately from the number of source URLs that the page actually exposes for audit.
2. A count difference such as 21 declared and 16 auditable no longer blocks the workflow when all source URLs exposed by the page were captured successfully.
3. Both counts and a human-readable explanation remain in `results.json`, the stage-one report and the stage-one workflow response.
4. Real acquisition defects still fail closed, including missed visible sources, a source surface that cannot be opened, an incomplete answer and a cited PDF without verifiable body text.
5. All other platform adapters and the four-stage fact-checking workflow remain unchanged.

## Verification evidence

- A deterministic Doubao regression covers the observed 21-declared/16-auditable semantics without prompting the user to abandon or replace the platform.
- A separate negative regression proves that a cited PDF with no verifiable body still fails and retains partial evidence for recovery.
- The complete skill and its collector module carry identical code, contracts and tests.
- Public release tests, public-tree audit, sensitive-data scan, reproducible build comparison and installed WorkBuddy acceptance must pass before promotion.
