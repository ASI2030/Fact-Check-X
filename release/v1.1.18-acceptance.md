# Fact-Check-X v1.1.18 acceptance record

Fact-Check-X v1.1.18 makes DKnow deep-trace evidence text readable and reports the running package version. It does not add a platform, external model API or workflow stage, and it does not change scoring.

## Accepted behavior

1. Evidence text captured from DKnow source cards is decoded when the platform delivers it percent-encoded. Decoding runs per contiguous escape run, so a truncated trailing sequence leaves only that fragment untouched instead of discarding the whole excerpt.
2. Text without a paired escape signature is never altered, so an excerpt containing a literal percent sign is stored unchanged.
3. `prepare-runtime` returns `installedVersion` with the version of the package that is actually executing and the file it was read from, taken from the running script's own directory rather than from any host installation record.
4. Existing four-stage workflow, dynamic `N>=1` platform selection, factual evidence gates and Computer Use recovery remain unchanged.

## Verification evidence

- Real-browser regression `dknow_percent_encoded_evidence_test.mjs` fails on the v1.1.17 collector with the reported symptom and passes on v1.1.18.
- Replaying ten archived DKnow capture pages reduces percent-encoded evidence fields from 22 of 305 references to 0 of 305. All affected references were deep-trace captures; standard chat captures were unaffected in every sample.
- `installed_version_test.py` asserts the reported version matches the package manifest, falls back to `SKILL.md` when the manifest is absent, and appears in `prepare-runtime` output.
- JavaScript collector tests: 16/16 passed. Independent-module Python tests: 10/10 passed. Complete-package Python tests: 12/12 passed. Mirror regression runner: 10 checks passed.
- Source and complete-package mirror comparison matched byte for byte; both entry scripts remain identical.

## Known and deferred

- DKnow evidence text can still carry an attachment URL prefix and inline HTML tags. This predates v1.1.18, affects both chat and deep trace, and is recorded for a separate change rather than folded into this release.
