# Fact-Check-X v1.1.16 acceptance record

Fact-Check-X v1.1.16 restores Doubao capture after the platform replaced its composer, stops reporting a missing chat input as a login problem, and keeps hidden DKnow reasoning text out of captured answers. It does not add a platform, external model API or workflow stage.

## Accepted behavior

1. The Doubao adapter locates the TipTap/ProseMirror composer (`.tiptap[contenteditable='true']`) and falls back to any visible `contenteditable` element; the previous `role="textbox"` and `textarea` selectors remain for older layouts.
2. An authenticated page that exposes no chat input returns status `input_not_found` with adapter-drift guidance. It is never labeled `login_required`, the interactive prompt does not ask the user to log in, the CLI stops mechanical retries with a message that names the real cause, and the recovery file carries the same guidance.
3. Captured DKnow answers contain only text rendered on the live page. Elements hidden on the original node (`display:none`, `visibility:hidden`, `hidden`) are removed from the cloned node before it is read, and the reasoning panel, thinking-status labels and knowledge-library button are excluded whether collapsed or expanded.
4. Existing four-stage workflow, dynamic `N>=1` platform selection, factual evidence gates and Computer Use recovery remain unchanged.

## Verification evidence

- Real-browser regressions `doubao_tiptap_input_test.mjs` and `dknow_hidden_reasoning_test.mjs` fail on the v1.1.15 collector with the reported symptoms and pass on v1.1.16.
- JavaScript collector tests: 13/13 passed; the collector smoke test and the complete-package regression runner passed.
- Independent-module Python tests: 10/10 passed. Complete-package Python tests: 11/11 passed.
- Replaying all ten archived DKnow capture pages from the five-question evaluation through the v1.1.16 extractor yields no hidden reasoning text; the v1.1.15 extractor leaked it in nine of ten.
- Live Doubao capture on v1.1.16 reports `login_required` for an expired collector session instead of `No visible chat input found`; live DKnow capture succeeds with a clean answer.
- Source and complete-package mirror comparison matched byte for byte.
