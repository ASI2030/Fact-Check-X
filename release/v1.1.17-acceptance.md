# Fact-Check-X v1.1.17 acceptance record

Fact-Check-X v1.1.17 restores DKnow footnote resolution and removes a deep-trace placeholder regression introduced in v1.1.16. It does not add a platform, external model API or workflow stage.

## Accepted behavior

1. References merge on citation identity, not on URL alone. When one source document backs several footnote markers, every marker keeps its own reference and stays resolvable in the answer.
2. A marker whose card exposes both the platform's internal mirror and the originating government URL yields one reference, and the externally verifiable address is retained.
3. Extraction never returns a hidden deep-trace progress placeholder as the answer. While the response body has not yet streamed, extraction returns empty so capture keeps waiting.
4. A DKnow capture whose answer is a progress placeholder, is shorter than the minimum length, or contains only the fixed lead-in is recorded as a failed capture rather than a success.
5. Whether an element is rendered is determined from its ancestor chain, so a panel hidden by an ancestor is excluded from the answer.
6. Existing four-stage workflow, dynamic `N>=1` platform selection, factual evidence gates and Computer Use recovery remain unchanged.

## Verification evidence

- Real-browser regressions `dknow_marker_merge_test.mjs` and `dknow_deep_research_placeholder_test.mjs` fail on the v1.1.16 collector with the reported symptoms and pass on v1.1.17.
- Replaying twelve archived DKnow capture pages (the five-question evaluation plus a reported production case) raises marker coverage from 185/269 = 68.8% on v1.1.16 to 269/269 = 100% on v1.1.17, with no duplicated or link-less references. The same replay on v1.1.14, before the URL-keyed merge was introduced, yields 269/270 = 99.6%, which places the defect in v1.1.15.
- JavaScript collector tests: 15/15 passed; the collector smoke test and the complete-package regression runner passed.
- Independent-module Python tests: 10/10 passed. Complete-package Python tests: 11/11 passed.
- Live capture of DKnow chat and deep trace on the reported question returns complete answers with no placeholder and no hidden reasoning text.
- Source and complete-package mirror comparison matched byte for byte.
