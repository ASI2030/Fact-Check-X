# Fact-Check-X v1.1.21 Acceptance

Status: release candidate verified. Publication receipts are added only after each exact distribution target is read back.

## Frozen scope

- A DKnow Deep Trace standalone page is complete only when its stream has ended, its step list is complete, and a substantive report body exists.
- Statutory conditions explicitly requested by the question are direct answers; narrower unrequested local extensions remain supplemental references.
- Source authority and claim support remain separate. Absence, exclusivity, and uniqueness claims require explicit same-claim evidence.
- Every comparison claim, answer excerpt, and bound evidence set must cover the same material facts. An overwide claim is a comparison-analysis error and blocks authority verification instead of being silently blamed on the platform.
- Recover readable source bodies from directly downloadable PDF and DOCX files and from browser-accessible HTML when the primary fetch path fails, while keeping genuine network and source failures explicit.
- Normalize MSYS-style Windows paths without changing native Windows, UNC, or POSIX paths.
