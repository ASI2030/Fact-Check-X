# Fact-Check-X v1.1.9 acceptance record

Fact-Check-X v1.1.9 closes the report ownership and staged-interaction issues frozen for this release. No platform, metric, or unrelated feature was added.

## Accepted behavior

1. Stage 3 owns the authoritative result. It presents only the evidence-supported direct answer, evidence boundaries, and a concise source index. Supplemental references remain reference-only and cannot enter the final answer.
2. Stage 4 consumes the locked Stage-3 result. It shows per-knowledge-point verification details and platform performance without recomputing the authoritative answer or repeating the former direct-answer and supplemental-reference matrices.
3. Every stage emits an independently openable report. Capture, comparison, and authority checkpoints each require the user's explicit acknowledgement before the next stage can start; there is no full-auto acknowledgement bypass.
4. All four reports share one information architecture, visual language, stage navigation, and responsive mobile layout.

## Verification evidence

- The same real Shenzhen spouse-settlement policy question completed all four stages with DeepSeek and Tencent Yuanbao.
- DeepSeek captured 7 of 7 referenced source bodies. Tencent Yuanbao captured 64 of 67; the remaining three acquisition failures were preserved as failures instead of being presented as verified source text.
- The run produced 11 atomic knowledge points. All 11 were supported by captured government sources, so Trusted Search was not invoked and the final authority result had no evidence gaps.
- Three deliberate attempts to skip user acknowledgement were rejected: capture to comparison, comparison to authority, and authority to delivery.
- The four reports were checked at desktop and mobile viewport sizes with no horizontal overflow. Stage 3 and Stage 4 were also inspected for direct-answer/reference separation and locked-result consistency.
- Nineteen Python regression tests, four JavaScript runtime suites, public-tree audit, sensitive-content scan, clean-package runtime checks, and two independent reproducible builds passed.
- The WorkBuddy installed copy passed runtime preparation, checkpoint behavior, and the complete smoke test.
